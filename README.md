### 🔧 What I'm working on

**Full-stack developer (apprenticeship) at [Marriage4Life](https://marriage4life.app)** — sole developer on two internal services (private repos, happy to walk through them in an interview):

- **Sophia, customer AI agent — live on five channels since November 2026.** One TypeScript service and one shared prompt replaced five separate n8n workflows. Sophia answers customers on WhatsApp, Instagram, website chat, office chat and email, and books and manages consultations through the company's API with Claude tool use. Shadow mode first, more than 250 tests including replays of masked real conversations, and the old agents on standby as a one-line rollback.
- **Consultant Monitoring Agent — in production since October 2026.** Reads consultant activity from the CRM, scores each working day, and sends managers daily and weekly reports plus live WhatsApp alerts. Rules are pure functions, alerts are claimed in the database before sending so none goes out twice, and it runs in Docker with its own PostgreSQL, CI and a watchdog.
